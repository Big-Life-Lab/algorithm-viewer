This repo contains the code for the algorithm viewer. The algorithm viewer is an
application to enable the developers of a model to better understand how they're
model works.

## Working with this Repo

* When working with files in this repository, check for README.md files within
  each folder. These READMEs contain specific instructions and guidelines for
  working with the files in that folder. Always read and follow these
  instructions before making changes.
* Follow an 80 character line length for all text files in this repository.
* Make sure there aren't any trailing spaces in each line

## Folder Structure

- [`docs/`](./docs) - Project documentation

## Common Commands

* Build and view the documentation:

  ```bash
  quarto preview ./docs
  ```
