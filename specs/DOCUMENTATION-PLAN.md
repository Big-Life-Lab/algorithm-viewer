# Initial Documentation Plan

This document contains the initial instructions and priorities for writing the Algorithm Viewer documentation. This document, including the suggested table-of-contents found in [DOCUMENTATION-TOC.md](DOCUMENTATION-TOC.md), provide the basis of the more complete writing plan found in [DOCUMENTATION-WRITING-PLAN.md](DOCUMENTATION-WRITING-PLAN.md).

## Task

Create the documentation plan and start writing, in the priority order agreed
2026-07-09 and reaffirmed 2026-07-23:

1. **User documentation** — top priority (the layer LLMs write worst): using
   and interpreting the viewer.
2. **Intent and scope** — why the viewer exists, use cases,
   appropriate/not-appropriate uses, features, roadmap (README-level).
3. **Architecture / code exploration** — deprioritized; AI tools (DeepWiki
   etc.) cover this need.

Frame: Divio (tutorials, how-to, explanation, reference). Must include the
repo-to-viewer integration how-to: wiring a repo (e.g. HTNPoRT) to the viewer
via a config file requires cloning the repo locally — the viewer cannot read a
repo remotely from GitHub.
